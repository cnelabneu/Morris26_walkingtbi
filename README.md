# Morris26_walkingtbi
This pulbic repo contains rcode to replicate Morris 2026 study on walking intervention after TBI

Four quarto documents contain the code used to generate the 1. feasibility and compliance results 2. efficacy results 3. modifier results and 4. outcome results. For now, the data necessary to run this code can be obtained by emailing the primary author of the paper and will be shared within 12 months of the study complettion date (May 31st 2026). The data will also become available on FITBIR at by the same date.
